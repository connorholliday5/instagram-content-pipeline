# Data Sources & Ethics

This project collects and analyzes *metadata* about comic releases (titles, issue numbers, dates, creators, short descriptions).
We aim to:
- Respect platform Terms of Service and robots.txt where applicable
- Rate-limit requests and cache responses to minimize load
- Avoid redistributing copyrighted content (e.g., full cover art) unless explicitly permitted
- Generate our own visual assets (charts/cards) from derived data
- Track provenance: source, timestamp, parameters, and hashes for reproducibility
